# Agent mistakes

Record mistakes found during self-testing or review when the lesson can prevent recurrence. Include the cause, correction, and verification. Use `[learned]` only when a systemic fix exists and is linked, such as a regression test or a corrected workflow; reading an entry is not a fix. Do not add entries when no mistake was found.
